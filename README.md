# VIBE — Music Website

A Spotify-inspired, minimal music landing page with mood/genre libraries and a player.

## Add your own music
Create an `audio` folder and place your ORIGINAL or properly licensed MP3 files there. Then update the song entries in `app.js`.

Example:
`["Song Name","Artist","audio/song.mp3"]`

## Deploy
Upload the folder to GitHub and import the repository into Vercel, or use Vercel's CLI.
